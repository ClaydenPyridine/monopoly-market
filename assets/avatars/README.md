# 角色头像

这 17 张是**原神（Genshin Impact）官方角色头像**，已按下面的文件名放好。
游戏会自动用真头像替换掉元素徽记，**不用改任何代码**。

## 来源

全部来自 **Enka.Network** 的公开素材目录（原神社区常用的公开素材 CDN）：

```
https://enka.network/ui/UI_AvatarIcon_<内部名>.png
```

**⚠️ 内部名 ≠ 英文名**，下面表格里记了每张图实际用的内部名——以后要换图或补角色，
直接照抄「内部名」那一列，别照抄英文名（用英文名会 404）。

## 规格

* **正方形**，256×256（棋盘上显示到 15px，详情页 46px，够用）。
* PNG / JPG / WebP 都行，扩展名写 `.png` 最省事。
* 会按**圆形裁切**，所以主体尽量居中（官方头像本身已居中，直接用即可）。
* 透明底（官方头像为透明底）。

## 换成真头像后

* 源码版：直接刷新浏览器就生效。
* 单文件版：跑一次 `npm run build`，打包脚本会把 `assets/avatars/` 里的图**一起内联成 base64**，
  产出的 `dist/地产股神.html` 依然是「一个文件发出去就能玩」，不依赖这个文件夹。
