# 给主机（你）的说明

> 这份文档里的命令都是**直接复制粘贴**用的，行首的 `>` 是终端提示符，**不要复制进去**。
> 所有路径都特意用 **ASCII 文件名**（`saves\EW85-ai-takeover.json` 这种），别改成中文名，原因见 7.5。

## 一、我该点哪个？看你想怎么玩

| 想怎么玩 | 双击这个 |
|---|---|
| **一台电脑，几个人轮流玩**（热座，最简单） | [`启动-本地热座.bat`](../启动-本地热座.bat) |
| **朋友在同一个 WiFi**，各看各屏幕 | [`启动-联机服务.bat`](../启动-联机服务.bat) |

> Windows 数字签名验证通过、签发者是 Cloudflare, Inc.），放在游戏文件夹里，你不用再下载任何东西。

## 二、联机当房主：三步

### 第 1 步：双击 `启动-联机服务.bat`

会弹出**一个黑窗口**，3 秒后自动打开浏览器。黑窗口里长这样：

```
  地产股神 · 联机服务已启动
  ─────────────────────────────────────────
  本机：      http://127.0.0.1:8787/
  局域网：    http://192.168.1.23:8787/    ← 同 WiFi 的朋友用这个
  ─────────────────────────────────────────
  进去后点「联机对战」→ 创建房间，把房间号发给朋友。
```

> ⚠️ **这个黑窗口就是服务器。玩游戏期间不要关它，也不要关电脑。**
> 玩完了直接关掉窗口 = 关服。

**第一次运行会弹 Windows 防火墙提示 → 点「允许访问」，并勾上「专用网络」**，否则朋友连不上。

### 第 2 步：在浏览器里创建房间

1. 自动打开的页面上点 **「联机对战」**
2. 填个名字 → 点 **「创建房间」**
3. 屏幕上会出现一个 **4 位房间号**（比如 `GY9R`），记下来

### 第 3 步：把地址和房间号发给朋友

把黑窗口里那行 **局域网地址** 和 **房间号** 发给他们（下面有一段可以直接复制的模板）。

朋友都进来后，你在房间里选：
* **人数**：4 人 / 3 人 / 2 人（**空位会自动补电脑**，所以 2 个人也能开）
* **时长**：25 季度（约 1 小时）/ 50 季度（约 2 小时）/ 75 季度（约 3 小时）

点 **「开始游戏」** 就开局了。

## 三、直接复制给朋友的模板

**同一个 WiFi 的话，复制这段改一下就行：**

```
地产股神开黑！3~4 人，各看各的屏幕。

1. 连上和我同一个 WiFi
2. 浏览器打开：http://192.168.1.23:8787/     ← 把这个地址换成你黑窗口里显示的那个
3. 点「联机对战」→ 输入房间号：GY9R → 填个名字 → 加入房间
4. 等我点开始

不用装任何东西，浏览器打开就行。中途掉线了**直接刷新页面**，会自动回到你的座位；
万一刷不回来，就点「联机对战」→ 输房间号 + 你刚才用的名字，能认回原来的座位。
```

（地址用**黑窗口里「局域网」那一行**，不要用 `127.0.0.1`，那是你自己电脑的地址。）

> 提醒朋友一句：**用同一个浏览器刷新**，别关掉再换个浏览器开——换浏览器等于换了个人，座位认不回来。

## 四、异地朋友（不在同一个 WiFi）

局域网地址（192.168.x.x）出了家门就没了。**最短路径：双击我给你准备好的那个 bat。**

| 方案 | 怎么做 | 特点 |

## 五、回合超时和掉线托管是怎么回事

你不需要做任何设置，服务端**自动**做这两件事，目的是别再出现"一个人掉线、整局卡住 40 分钟"。

### 回合超时：谁磨蹭都不怕

轮到某个人的时候，他的屏幕上有**倒计时**，时间一到就由服务端替他走最保守的一步：

| 卡在哪一步 | 多久算超时 | 服务端替他做什么 |
|---|---|---|
| 该掷骰子 / 要决定买不买地 / 抽到事件卡 / 在监狱里 | **90 秒** | 自动掷骰、**放弃买地**、接受卡片、继续蹲监狱 |
| 交易阶段（掷完骰子之后在升级/买卖） | **180 秒** | 直接结束回合 |

关键一句：**它绝不替人花钱**——不替他买地、不替他交保释金、不替他买股票和金融产品。

秒数不是我拍脑袋定的，是照真人实测定的：掷骰那一类真人最慢也就 59 秒，90 秒基本不会误伤；
交易阶段真人的中位数就有 54 秒、最长的一个人用了 207 秒，所以给到 180 秒。

日志里会写一条「⏱ XX 超时未操作，已自动…」，你能看见是谁在磨蹭。

### 掉线托管：只有该他动的时候才接管

* **只有轮到他的回合、而且静默超过 60 秒**，才把他的座位交给电脑。
* 在**别人**的回合里他没动静，不会被误伤——那会儿他本来也不用做任何事。
* 请求还挂着的（网页开着、网络正常）一定算在线，不会被误判。
* 托管是**临时的、可认回的**：他回来自动拿回座位，日志会写「👤 XX 回来了，重新接管自己的座位」。
  电脑可能在这中间替他做过决定（比如放弃了一块地），但**没花过他的钱**。

### 有人中途想加入？现在可以

以前开局了就不让进。现在只要房间里还有**纯电脑座位**（创建房间时人数没填满，空位自动补的电脑），
新人可以**顶替一台电脑**坐进来继续玩，他会看到一个「顶替电脑座位」的选项。

两种人**不会**被顶替：
* **掉线玩家的座位**——那保留给本人回来认领，别人抢不走；
* 还在线的真人。

## 六、遇到掉线怎么办（存档恢复）

**先分清两种情况，别一上来就重启服务端。**

### 情况 1：只是某个人掉线（最常见）

什么都**不用做**，让他自己刷新页面就行。刷新后浏览器里存着身份，会自动回座位；
就算已经被电脑托管了，回来也会立刻交还。

**注意**：是**刷新**，不是"关掉重开一个浏览器"。如果他用的是无痕窗口，或者清了浏览器数据，
那就让他走「联机对战」→ **输房间号 + 原来的名字**，照样能认回座位。

### 情况 2：服务端崩了 / 你手滑关了黑窗口

这时候房间没了，得**从存档恢复**。好消息是：**cloudflared 的隧道窗口可以不动**——
公网网址不变，朋友那边不用改链接，只要刷新页面。

**恢复对局**（前提是你**事先抓过一份存档**、并复制成了 ASCII 名，见 6.1）：

```powershell
node server.mjs 8787 --restore saves\EW85-ai-takeover.json
```

**恢复的同时给某人发钱**（比如中途掉线害他少收了几轮租金，给他补一笔）：

```powershell
node server.mjs 8787 --restore saves\EW85-ai-takeover.json --pay "Pygg=40000"
```

`--pay` 可以写多次，一次发到位；`-40000` 就是扣钱。名字要跟游戏里**完全一样**。

**其实最简单的做法是双击现成的脚本：**

> [`恢复存档-EW85.bat`](../恢复存档-EW85.bat)

它内部就是上面第一条命令，用的是 ASCII 路径 `saves\EW85-ai-takeover.json`；
而且会先检查存档在不在、没装 Node.js 还会自动帮你打开下载页。
**你自己的房间号不一样的话，照 6.1 抓一份存档、改名成 ASCII，再把命令换掉就行。**

> ⚠️ **恢复前先把旧的黑窗口关掉**，不然会报 `EADDRINUSE`（8787 端口被占）。
> 恢复后**房间号不变**，让朋友刷新页面（或者用房间号 + 原名认回座位）。

### 6.1 抓存档（服务端还活着的时候）

**趁服务端还活着的时候先抓一份**，出事才有得恢复：

```powershell
node tools/snapshot.mjs EW85
```

* `EW85` 换成你的 4 位房间号。
* 想把某个座位先交给电脑接管的：

  ```powershell
  node tools/snapshot.mjs EW85 2
  ```

  `2` 是**座位号**（从 1 开始数），表示这个座位恢复后直接由电脑来打。
* **产物在 `logs\` 里**，长这样：`logs\存档-EW85-Q14-2026-02-14T21-30-00.json`。
  命令跑完它自己会把**可以直接复制的恢复命令**打印出来，照着复制最省事。
* 不确定有哪些房间？看 7.1 的 `GET /api/rooms`。

> ⚠️ **存档要拿去恢复之前，先给它改成 ASCII 文件名**（原因见 7.5）。
> 用 PowerShell 复制一份到 `saves\` 并顺手改名——房间号是英文数字，不用担心编码：

```powershell
New-Item -ItemType Directory -Force saves | Out-Null
Copy-Item "logs\存档-EW85-*.json" "saves\EW85-latest.json"   # 复制并改成 ASCII 名
```

以后**恢复就用 `saves\EW85-latest.json` 这个 ASCII 路径**，永远不要在命令行里敲中文文件名。
（实在懒得敲命令，就在文件管理器里把 `logs\` 那份存档**复制粘贴到 `saves\` 并改名**，效果一样。）

### 6.2 恢复后大家怎么回来

对**所有**玩家，一句话就够：

> **刷新页面**；不行就点「联机对战」→ 输房间号 + **原来的名字** → 加入。

房子、股票、现金全在存档里，不会丢。

## 七、后台能力（你自己偷偷看的）

这些是给你（房主）排错和救场用的，**朋友用不到**。凡是列在这里的接口都**只认本机**：
从公网隧道过来的请求会被 **403 拒绝**——否则拿到隧道网址的人就能枚举房间并闯进来。

### 7.1 看现在有哪些房间

浏览器直接打开（或者用 `curl`）：

```powershell
curl.exe http://127.0.0.1:8787/api/rooms
```

会返回每个房间的房间号、有没有开局、打到第几季度、每个座位的名字/是不是电脑/在不在线、
以及这个房间空闲了多少秒。**必须从房主这台机器上访问**。

### 7.2 给某个玩家加钱 / 扣钱

```powershell
curl.exe -X POST http://127.0.0.1:8787/api/admin/pay -H "content-type: application/json" -d "{\"room\":\"EW85\",\"name\":\"Pygg\",\"amount\":40000}"
```

* `room` 房间号、`name` 玩家名字（跟游戏里完全一样）、`amount` 正数加钱、负数扣钱。
* 同样是**只允许本机**。
* 如果服务端已经重启过，用 `--restore ... --pay "名字=40000"` 更省事（见 6.1 上面的命令）。

### 7.3 启动参数一览

| 命令 | 作用 |
|---|---|
| `node server.mjs` | 正常起服，默认 8787 端口 |
| `node server.mjs 8899` | 换个端口（8787 被占的时候用） |
| `node server.mjs 8787 --restore saves\EW85-ai-takeover.json` | 从存档恢复对局（断线救援） |
| `node server.mjs 8787 --restore saves\EW85-ai-takeover.json --pay "Pygg=40000"` | 恢复的同时发钱，`--pay` 可以写多次 |

### 7.4 观察工具：想自己看一局

都是**只读**的，不会影响正在玩的人。

| 命令 | 干什么 |
|---|---|
| `node tools/watch.mjs EW85` | 实时旁观+录制一局，产出 `logs\对局-EW85-<时间>.jsonl` |
| `node tools/report.mjs` | 把录制变成中文战报（Markdown） |
| `node tools/night-report.mjs` | 汇总 `logs\` 里所有录制文件，给整晚的分析 |

* `watch.mjs` **全程只读**，不碰对局状态，别人不会察觉。
* 不写房间号也行：`node tools/watch.mjs` 会自动挑一个。
* 想指定录哪份：`node tools/report.mjs logs\对局-EW85-2026-02-14T21-30-00.jsonl`。
  （`logs\` 里的录制文件名带中文前缀，**直接从文件名复制整个路径**，别手打。）

### 7.5 一条重要经验：**存档文件名必须用 ASCII**

这是我实测踩过的坑：**中文文件名从 PowerShell 传给 cmd（bat）会被编码搞坏**，
`--restore` 找不到文件、服务端起不来，**游戏停了 1 分钟**。

具体是这样：`snapshot.mjs` 抓出来的存档叫 `存档-EW85-Q14-<时间>.json`（中文名），
直接在 `.bat` 里写这个路径就会出事。所以救场时**多走一步**：

1. 抓存档：`node tools/snapshot.mjs EW85`
2. **复制成 ASCII 名**（PowerShell 通配符拿文件，中文不用你敲）：

   ```powershell
   Copy-Item "logs\存档-EW85-*.json" "saves\EW85-latest.json"
   ```

3. 恢复：`node server.mjs 8787 --restore saves\EW85-latest.json`

所以规矩是：**`saves\` 里一律放 ASCII 文件名**（`EW85-latest.json`、`EW85-ai-takeover.json`、`NFYD-latest.json` 这种），
现成的恢复脚本 [`恢复存档-EW85.bat`](../恢复存档-EW85.bat) 也是照这个规矩写的。

**房间号、玩家名字用中文没问题**（`--pay "名字=40000"` 里的名字可以是中文），
只有**文件名**不能是中文。

## 八、出问题怎么办

| 现象 | 原因 / 怎么办 |
|---|---|
| 双击 bat 一闪而过 | 没装 Node.js。去 <https://nodejs.org> 装 LTS 版，装完重新双击 |
| 黑窗口报 `EADDRINUSE` | 8787 端口被别的程序占了。换端口：在文件夹里开终端跑 `node server.mjs 8899`，地址就变成 `:8899` |
| 黑窗口说"没有找到 Node.js" | 同上，装 Node |
| 朋友打开显示"无法访问此网站" | ① 是不是把 `127.0.0.1` 发过去了？要发 `192.168.x.x`；② 是不是同一个 WiFi；③ 防火墙有没有放行（第一次运行要允许 + 勾专用网络）；④ 公司/学校网络常常禁止设备互访，换手机热点试 |
| 朋友说"没有这个房间号" | 房间号是 4 位大写字母。你重启过服务端的话旧房间号就失效了，重新创建 |
| 朋友刷新后座位没了 | 正常会自动回座位。清了浏览器数据才会丢——让他「联机对战」→ **房间号 + 原来的名字**，还能认回来（见第六节） |
| 朋友掉线了 / 一直不动 | 不用管。服务端 60 秒后自动让电脑接管他的座位，他刷新一下就回来了（见第五节） |
| 有人发呆不点，整局卡住 | 不会卡死。掷骰/买地/事件/监狱 **90 秒**、交易 **180 秒** 后服务端替他走最保守的一步，且**不替他花钱** |
| 中途想加人 | 房间还有**纯电脑座位**就能顶替进来；没有就只能等下一局（掉线玩家的座位不给别人抢） |
| 服务端崩了 / 黑窗口被关了 | 别急着重开房间：`node server.mjs 8787 --restore saves\EW85-ai-takeover.json`，或双击 [`恢复存档-EW85.bat`](../恢复存档-EW85.bat)。cloudflared 窗口不用关，网址不变（见第六节） |
| 恢复存档时报找不到文件 | 检查存档路径；**文件名必须 ASCII**，中文名从 PowerShell 传给 cmd 会乱码（见 7.5） |
| 想看看现在有哪些房间 | `curl.exe http://127.0.0.1:8787/api/rooms`，**只能在本机访问**（见 7.1） |
| 玩完怎么关 | 直接关掉那个黑窗口 |

## 九、开局前能改的东西

都在那个黑窗口对应的游戏里，房主点「开始游戏」之前可以选：

* **人数**：2 / 3 / 4（空位补电脑：电脑·老王 / 阿May / 铁柱 / 小满）
* **时长**：25 / 50 / 75 季度

改完跑一次 `npm run build` 重新打包单文件版。

## 十、热座模式（不用开服）

双击 [`启动-本地热座.bat`](../启动-本地热座.bat)（或直接双击 [`dist/地产股神.html`](../dist/地产股神.html)），
在一台电脑上选好人数和电脑数量就能玩，4 个人挤一台电脑轮流点。

**操作**：空格 = 掷骰子 / 结束回合｜`M` 股市｜`P` 玩家｜`F` 金融｜`C` 折叠中央面板｜`Esc` 关面板。
