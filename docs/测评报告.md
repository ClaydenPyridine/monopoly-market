**范围**：规则回归、界面端到端（源码版＋单文件版）、联机集成、320 轮自动调参、公网隧道实测。

**查出并修复**：

1. 股票同回合买卖往返可无风险刷钱 → 改为先吃滑点再成交＋双向 1% 手续费，往返必亏 2.8%，加回归测试钉死。
2. 三个启动 .bat 的中文被 cmd 拆坏（65001/936 代码页冲突）→ bat 改成纯 ASCII，中文交给 Node 输出。
3. 公网 POST 实测丢包 25% → 真因是 IPv6 通路不通（IPv4 10/10 全通，IPv6 0/10）；已加 8 秒超时＋3 次重试＋服务端幂等，重试不会重复扣钱。
4. AI 抽到事件卡会弹窗阻塞流程 → 改为自动翻牌。

**结果**：四套测试全绿。~~调参得分 0.867 → 0.980~~（已作废，见顶部说明）。
