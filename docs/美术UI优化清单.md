# 美术 / UI 优化清单（v0.9 → v1.0）

> 功能已经齐了。这份清单是下一步"只改观感、不动规则"的施工图。
> 基线截图：[`before-main.png`](before-main.png)、[`before-market.png`](before-market.png)

---

## 一、现状盘点

### 已有的美术资产

| 项目 | 实现方式 | 评价 |
|---|---|---|
| 配色体系 | CSS 变量（深蓝底 + 金/蓝点缀） | 完整，但偏"金融终端" |
| 地区色彩 | 8 个地区各配一个**元素色** | 有用，但只体现在细色条上 |
| 地块头像 | 元素徽记 SVG + 可选真头像槽 | 机制就绪，视觉太小 |
| 四角格子 | 各自一个内联 SVG 图标 | 有，但和普通格子区分度低 |
| 骰子 | CSS 画点 + 滚动动画 | 不错 |
| 棋子 | 彩色圆点 + 当前格呼吸高亮 | **太弱** |
| 指数走势图 | Canvas/SVG 面积图 | 占地方，信息密度低 |
| 事件卡 | 纯色卡片 + 文字 | 无插画 |
| 字体 | 系统中文字体栈 | 无标题字 |

### 元素色（已经在用，可以放大利用）

每个地区绑定一个元素色，目前只用在细色条上。**这是最大的未被利用的视觉资源。**

---

## 二、问题清单（按"影响观感"排序）

### 🔴 P0：一眼就能看出来的短板

**1. 地块没有"建筑感"**
现在地产等级用 1–5 个金色小方块表示。**完全看不出"这里盖了楼"**——而这是大富翁最核心的视觉爽点。
→ 玩家花 4 万盖到"地标"，屏幕上只是多了几个小黄块。

**2. 棋子太弱**
彩色圆点直径很小，4 个人挤在一格时几乎分不清谁是谁，也不知道朝向。当前回合只有轻微高亮。
→ 联机时"我的棋子在哪儿"要靠找。

**3. 中央面板比例失衡**
左侧 REI 图占了约 **54%** 宽度，但只有一条线 + 一个大数字；右侧塞了 5 个信息块。
→ 左边大片空白，右边略挤（矮窗口还会触发滚动）。

**4. 四角格子不够"特殊"**
起点/监狱/免费停车/入狱应该有明显不同的视觉重量，现在只是底色略深 + 一个小图标。

### 🟡 P1：提升质感

**5. 整体偏冷、缺"提瓦特感"**
所有面板都是同一套深蓝渐变。虽然有元素色可用，但视觉上仍是"金融软件"而不是"提瓦特地产"。

**6. 缺少动态反馈**
- 升级地块 → 没有"长高"的过程
- 收到租金 → 金币没有飞向自己
- 股价变动 → 只有数字颜色变化，没有脉冲
- 破产/追缴 → 没有冲击感

**7. 背景过于扁平**
有极细的网格和两个径向光晕，但整体还是一块纯色。

### 🟢 P2：锦上添花

**8. 事件卡无插画**（需要素材）
**9. 无标题字体**
**10. 无音效**

## 三、改进方案（不依赖任何外部素材，全部可用 CSS/SVG 做）

### P0-1 地块建筑可视化 ⭐ 收益最大

把等级 1–5 画成**不同轮廓的建筑剪影**，用 SVG 内联到每个地块底部：

| 等级 | 名称 | 视觉 |
|---|---|---|
| 0 | 空地 | 一块地皮 + 虚线地基 |
| 1 | 小屋 | 单层小房子 |
| 2 | 公寓 | 三层楼房 |
| 3 | 写字楼 | 高层方楼 + 窗户点阵 |
| 4 | 地标 | 带尖顶/塔楼的地标轮廓 |
| 5 | 地标（满级） | 加上发光/金边 |

- 建筑用**该地块的元素色**填充
- 等级越高，剪影**越高、越大**，占满格子下半部
- 未升级的地块显示"虚线地基"，形成"这块地还没开发"的暗示

**效果**：扫一眼棋盘就能看出哪个地区被开发到爆，谁在囤地不盖楼。

**工作量**：中（5 个 SVG 剪影 + 按等级切换 + 布局微调）

---

### P0-2 棋子升级

- 从圆点改成**带形状的小棋子**：圆形底 + 朝向指示 + 白边
- 直径加大，**带投影像图钉一样"钉"在格子上**
- 当前回合的棋子：**金色光环 + 轻微上下浮动**
- 同一格多人时**自动散开**（现在是堆叠）

**工作量**：小到中

---

### P0-3 中央面板重排

- REI 走势图**缩小并移到面板顶部当横幅**（或做成背景水印），高度砍一半
- 让出的空间给「当前回合 + 骰子 + 操作按钮」——**这才是玩家真正盯着看的东西**
- 数值块改成**横排的胶囊**，减少纵向占用
- 目标：矮窗口（1366×768）**不需要滚动**

**工作量**：中

---

### P0-4 四角格子特化

| 格子 | 视觉 |
|---|---|
| 七天神像（起点） | 金色神殿剪影 + 高光 |
| 梅洛彼得堡（监狱） | 铁栅栏纹理 + 冷蓝 |
| 冒险家协会 | 向上的箭头 + 绿色 |
| 摩拉税 / 奢侈税 | 金币堆 + 红色警示边 |

**工作量**：小

---

### P1-1 元素色彩系统（让主题立起来）

- 每个地区的地块**边框、建筑填充、悬浮光晕**全部用该地区的元素色
- 垄断一整组时，该组格子**整体泛该元素色的光**
- 棋盘背景加一层**极淡的元素色径向渐变**（蒙德=风青、璃月=岩金、稻妻=雷紫…）

**工作量**：中（主要是调色和试探）

---

### P1-2 动态反馈

| 事件 | 动效 |
|---|---|
| 升级 | 建筑**从地基长高**（0.3s），完成时闪一下金光 |
| 收到租金 | 一串金币从付款方**飞向收款方**的棋子 |
| 股价跳动 | 数字**脉冲放大**一次 |
| 被追缴 | 地块**红色描边闪烁** 3 次 |
| 破产 | 棋子**碎裂/淡出** |
| 轮到我了 | 面板边缘**呼吸一圈** |

**工作量**：中（金币飞行需要一点 JS）

---

### P1-3 背景质感

- 棋盘外圈加**暗角（vignette）**
- 面板加**极细噪点**（CSS `background-image` + SVG feTurbulence 或重复 PNG data-URI）
- 顶栏/底栏加**内阴影分隔线**

**工作量**：小

| 优先级 | 素材 | 规格 | 没有的话 |

## 五、建议施工顺序

| 阶段 | 内容 | 预计改动 |
|---|---|---|
| **第 1 步** | 地块建筑可视化 + 棋子升级 | `styles.css` `src/ui.js` |
| **第 2 步** | 中央面板重排（解决矮窗口滚动） | `index.html` `styles.css` |
| **第 3 步** | 元素色彩系统 + 四角特化 | `styles.css` |
| **第 4 步** | 动态反馈（升级/收租/追缴） | `src/ui.js` `styles.css` |
| **第 5 步** | 背景质感 + 收尾 | `styles.css` |
| **第 6 步** | 有素材的话接入头像/插画/字体/音效 | `assets/` + 打包脚本 |

**每一步都能单独验收**，改完跑一遍：

```powershell
npm test                          # 四套测试全过
node tools/build-single.mjs       # 重新打包
```

并按 1600×940 / 1440×820 / 1366×768 三个分辨率截图确认布局没坏。

## 六、两条硬约束（别踩）

1. **不能引入任何外部依赖**——不允许 CDN、不允许 npm 包、不允许外部图片链接。
   所有图形必须用 **CSS / 内联 SVG / 用户放进 `assets/` 的图** 实现。

2. **不能改游戏规则**——这一轮只动观感。任何涉及 `src/engine.js` 的改动都要单独讨论。

---

## 七、一句话总结

**现在最大的视觉浪费是"元素色只用在细色条上"和"地产等级看不出是建筑"。**
把这两点做实（P0-1 + P1-1），整个棋盘会从"金融数据面板"变成"看得见的提瓦特地产版图"。
