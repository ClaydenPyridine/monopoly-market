# 给朋友：怎么进来一起玩

你**什么都不用装**，有个浏览器就行。

---

## 你要的东西

房主会发给你两样：

1. **一个网址**，长得像 `http://192.168.1.23:8787/`
2. **一个 4 位房间号**，长得像 `GY9R`

---

## 三步进来

### 1. 连上房主所在的 WiFi

如果房主发的是 `192.168.x.x` 开头的网址，说明你们得在**同一个 WiFi** 下
（房主开手机热点、你连上去也算）。

如果发的是 `https://xxxx.trycloudflare.com` 或者 `http://100.x.x.x:8787`，
那就不用管 WiFi，直接下一步。

### 2. 浏览器打开那个网址

手机、平板、电脑都行，用哪个浏览器都行（Chrome / Edge / Safari / 微信内置浏览器都可以）。

### 3. 点「联机对战」→ 输房间号 → 加入

* 填个名字
* 房间号填 4 位字母（不区分大小写）
* 点「加入房间」

进去后会看到四个座位，你在其中一个。**等房主点「开始游戏」** 就开局了。

> **记住你填的名字**：中途掉线要用「房间号 + 这个名字」认回座位。
> 也用**同一个浏览器**玩，别换来换去。

> 来晚了一步？如果房间里还有电脑座位，你会看到**「顶替电脑座位」**，
> 照样能中途坐进去接着玩（别人掉线的座位不给你抢，那是留给本人的）。

---

## 玩的时候

* **轮到你了**，屏幕中间的按钮才会亮，点「掷骰子」
* 轮到你的时候屏幕上还有个**倒计时**，剩 30 秒会变成琥珀色——别发呆，
  时间到了系统会替你走最保守的一步（**不会替你花钱**，但会替你放弃买地）
* 骰子所有人一起滚，棋子所有人一起动
* 走到无主地会**只弹给你**一个买地窗口，买或放弃
* **股票不用等轮到你**——任何人的回合你都能点右边 **「股市」** 看行情、买卖
  （只有两种情况不行：自己在坐牢，或者场上有人正弹着买地窗口）
* 想升级 / 抵押 / 卖回银行、或者买风险投资卡、垃圾债券、期权、保险、定期存单，
  就在自己掷完骰子之后的交易阶段点右边 **「金融」**，弄完点 **「结束回合」**
* 页面上方有 `M` / `P` / `F` 三个抽屉按钮和快捷键，`C` 可以把中间那块大面板折叠起来，棋盘看得更清楚
* 想翻之前的记录，点事件日志上的 **`⤢ 展开`** 全屏看，按 `Esc` 收起

**注意**：股票是**先吃滑点再成交**、买卖各收 1% 手续费，所以**同一回合里买了再卖必亏**，别想着刷差价。

---

## 出问题

| 现象 | 怎么办 |
|---|---|
| 打不开 / 一直转圈 | 检查是不是连上了房主的 WiFi；问房主黑窗口还开着没 |
| 说「没有这个房间号」 | 房间号是 4 位大写字母，让房主再确认一遍 |
| 说「房间满了」 | 4 个座位全是真人，等下一局 |
| 说「这局已经开打了」 | 房间里没有空着的电脑座位了。**如果有**「顶替电脑座位」这个选项，就能直接进去接着玩 |
| 中途刷新了页面 | 正常情况下会自动回到你的座位，稍等一下就好 |
| **掉线了怎么回来** | ① **原浏览器直接刷新**，自动回座位；② 刷不回来就点「联机对战」→ 输**房间号 + 你原来的名字** → 加入，照样能认回自己的座位（房子股票现金都还在） |
| 卡住了 / 不动 | 刷新页面试试，会自动回座位 |
| 掉了一会儿，回来发现是电脑在替我打 | 正常，你掉线超过 60 秒、又正好轮到你，系统就先让电脑替你；你一回来座位立刻还给你 |
| 有个人一直不动 | 不用等他磨蹭。轮到他超过 60 秒，或那一阶段超时（掷骰类 90 秒、交易 180 秒），系统会替他走一步，不会把整局卡住 |
| 屏幕顶上出现一条提示 | 那是掉线提示横幅，说明正在自动重连，等它消失就行 |

---

## 一句话总结

**浏览器打开房主给的网址 → 联机对战 → 填名字和房间号 → 加入 → 等房主开始。**

掉线了：**先刷新**；还不行就 **房间号 + 原来的名字** 再来一次。股票**不用等轮到你**也能看能买。
